## ১. লক্ষ্য

- ভিডিও ইমপোর্ট → ফিল্ম লুক প্রিভিউ → ফুল স্পেকট্রাল এক্সপোর্ট (MP4)
- ছবির মতোই: ফিল্ম + পেপার + স্লাইডার, কিন্তু ভিডিও-উপযোগী ডিফল্টসহ

## ২. দুই-স্তর কৌশল

### স্তর ১ — রিয়েল-টাইম প্রিভিউ (LUT)
- বর্তমান ফিল্ম+পেপার+এনলার্জার সেটিংস থেকে **33³ 3D LUT** বেক (ইঞ্জিনের বিদ্যমান LUT এক্সপোর্ট ব্যবহার করে)
- `MediaCodec` ডিকোড → OpenGL ES 3D-LUT শেডার → `MediaCodec` এনকোড (পাস-থ্রু প্রিভিউ) অথবা `TextureView` প্রিভিউ
- 720p/1080p-তে 30fps লক্ষ্য; LUT বেক ~১-২ সেকেন্ড (একবার, সেটিংস বদলালে আবার)

### স্তর ২ — ফুল স্পেকট্রাল এক্সপোর্ট
- প্রতিটি ফ্রেম → একই Vulkan ইঞ্জিন (`spektra-core`) দিয়ে প্রসেস → H.264/H.265 এনকোড
- Grain: ফ্রেম-ইনডেক্স থেকে seed (অ্যানিমেটেড, কিন্তু স্থিতিশীল)
- Halation/diffusion: প্রতি ফ্রেমে (স্পেশাল — টেম্পোরাল স্মুথিং নেই, ফিল্মের মতোই)
- অডিও: `MediaExtractor`/`MediaMuxer` দিয়ে AAC পাস-থ্রু (রিএনকোড নয়)

## ৩. পারফরম্যান্স বাজেট

| রেজোলিউশন | প্রতি ফ্রেম (GPU) | ১০s @30fps এক্সপোর্ট |
|---|---|---|
| 720p | ~০.০৫-০.১s | ~১.৫-৩ মিনিট |
| 1080p | ~০.১-০.৩s | ~৩-৯ মিনিট |
| 4K | ~০.৫-১s+ | ১০+ মিনিট (পরে অপ্টিমাইজ) |

- ব্যাকগ্রাউন্ড `WorkManager`/`ForegroundService` + নোটিফিকেশন প্রগ্রেস
- প্রিসেট: 720p (দ্রুত), 1080p (কোয়ালিটি), Original (শুধু ছোট ক্লিপ)

## ৪. UI ফ্লো

```
Video ট্যাব → পিক ভিডিও → ফিল্ম/পেপার পিক (ছবির মতোই)
  → প্রিভিউ (LUT, প্লে/পজ, স্লাইডার)
  → এক্সপোর্ট সেটিংস (রেজোলিউশন, ফরম্যাট, অডিও)
  → ব্যাকগ্রাউন্ড এক্সপোর্ট → গ্যালারি/শেয়ার
```

## ৫. মাইলস্টোন

1. **V1:** LUT প্রিভিউ + 720p ফুল-স্পেকট্রাল এক্সপোর্ট (প্রোটোটাইপ)
2. **V2:** 1080p + H.265 + ব্যাকগ্রাউন্ড + প্রগ্রেস
3. **V3:** 4K + টাইল্ড প্রসেসিং + ক্যামেরা-রেকর্ডিং (লাইভ লুক)

## ৬. রিস্ক

- থার্মাল থ্রটলিং (লম্বা এক্সপোর্টে) → চাঙ্কড প্রসেসিং + কুল-ডাউন
- মেমরি (4K ফ্রেম) → টাইল্ড/স্ট্রিমিং পাইপলাইন
- ডিভাইস কভারেজ (Vulkan 1.1+) → CPU ফলব্যাক (ধীর, কিন্তু কাজ করবে)
